# Octagram

موقع Octagram بتكوين سينمائي يحافظ على هوية الشركة والشعار الأصلي، بمظهر داكن ومشاهد ثلاثية الأبعاد. نُقل التطبيق إلى **Next.js App Router، React 19، TypeScript وTailwind CSS 4**. يُرسم المحتوى كـ JSX على الخادم، وتُحمّل تجربة React Three Fiber على العميل فقط.

## النسخة الحالية

- عين افتتاحية وختامية متحركة، وتواصل مختصر بأيقونتي WhatsApp وInstagram.
- WhatsApp: `+962780668491`، وInstagram: `@octagram.jo`.
- الواجهة بلا أسهم وبلا أزرار إيقاف الحركة؛ يبقى احترام إعداد تقليل الحركة في النظام.
- تخطيط الخدمات والعين محجوز قبل التحميل لمنع القفزات، وتحميل WebGL مرتبط بقرب المشاهد من الشاشة.
- خامة Blender المستخدمة في البطاقات مضغوطة إلى WebP؛ ملفات Blender الأصلية محفوظة في `assets/source/`.

## النشر على GitHub Pages

الموقع العام: https://octagramjo.com/

النشر مُدار عبر `.github/workflows/deploy-pages.yml`. كل تحديث على `main` يثبّت الاعتماديات من ملف القفل، ويبني Next.js، ويفحص ملفات التصدير، ثم ينشر مجلد `out/` فقط. يمكن إعادة النشر من تبويب Actions عبر **Build and deploy Octagram → Run workflow**.

في **Settings → Pages → Build and deployment** يجب اختيار **GitHub Actions** كمصدر للنشر، مع إبقاء الدومين `octagramjo.com` وHTTPS. لا تختَر نشر جذر فرع `main` مباشرة؛ فهو يحتوي على المصدر وREADME وليس الموقع المبني. المسارات مضبوطة للنشر على جذر الدومين المخصص.

## التشغيل

هذا المستودع يحتوي على ملفات المصدر. مجلد `out/` وملفات `node_modules/` غير مرفوعة؛ أنشئ نسخة الإنتاج بالأوامر أدناه أولًا. بعد البناء يمكن على macOS فتح `Preview.command` لتشغيل المعاينة.

يتطلب Node.js **20.9 أو أحدث**. ثبّت الإصدارات المحددة في ملف القفل، ثم أنشئ نسخة الإنتاج وشغّلها:

```sh
npm ci
npm run build
npm start
```

افتح `http://localhost:4173`. ينتج `npm run build` التصدير الثابت داخل `out/`، ويخدم `npm start` هذا المجلد محليًا. أعد البناء بعد تعديل الكود أو المحتوى. لا تفتح ملفات HTML بالنقر المزدوج؛ المشاهد تحتاج خادم HTTP لتحميل الأصول والبيانات المحلية.

للتطوير مع التحديث التلقائي:

```sh
npm run dev
```

يعمل خادم التطوير على `http://localhost:4174`.

يستخدم بناء الإنتاج مسار Webpack المدعوم في Next.js (`next build --webpack`)؛ يتجنب اعتماد Turbopack على فتح منفذ داخلي الذي منعته بيئة التنفيذ أثناء هذا التحديث.

## محتوى الشركة المعتمد

أُدرج البورتفوليو الذي قدمته كاملًا: ثماني مجموعات خدمات، ثلاثة مشاريع، مبادرتا THINK وOCTACARE، مراحل العمل الخمس، وأعضاء الفريق الأربعة مع الأدوار والسير وروابط LinkedIn المتاحة. تُعرض التفاصيل الطويلة داخل أقسام قابلة للتوسيع مع بقائها نصوص HTML قابلة للفهرسة.

- `src/lib/company-content.ts`: النصوص المعتمدة، الخدمات، القطاعات، المنتجات، المنهجية ومعلومات التواصل.
- `src/lib/site-config.ts`: المشاريع، أعضاء الفريق وروابطهم، عنوان الموقع وقناة التواصل.
- `assets/source/company-portfolio-2026.txt`: نسخة من النص الأصلي الذي قدمته، للرجوع إليه عند التحرير.

حالة Six Senses هي Delivered، وحلّ Octaclub مكان Medical Club كمنصة مطورة للتخصصات الطبية والتقنية في جميع الجامعات الأردنية والتعلم الذاتي مع THINK AI. لم يُفترض وضع إطلاق لـ ThaaerFit. تبقى THINK وOCTACARE مبادرتين قيد التطوير. لم تُضف أرقام نتائج أو عملاء أو شهادات غير واردة في النص.

روابط المشاريع وInstagram والموقع الرسمي مضافة. لم يتضمن المصدر صور أعضاء الفريق أو بريدًا رسميًا؛ تعرض بطاقات الفريق حروف الأسماء ورسوم الهوية. يمكن إضافة الصور المعتمدة داخل `public/assets/` ثم تحديد `image` و`imageAlt` في سجل الشخص. تُرسم البيانات بعناصر React مع تهريب النصوص والتحقق من مخططات الروابط.

النموذج يجهز ملخص طلب محليًا للنسخ أو التنزيل ولا يرسل بيانات تلقائيًا. إذا أضفت `contactEmail` في `site-config.ts`، يظهر خيار فتح الملخص في برنامج البريد ليرسله الزائر بنفسه. `contactUrl` مرتبط حاليًا بحساب Instagram الرسمي.

## الهوية والمشاهد

الشعار مشتق مباشرة من `octagram logo1.pdf`: **ثماني مجموعات تحافظ على المسارات الاثني عشر**، بما فيها القطع الداخلية والفراغ المركزي الحقيقي. إحداثيات المصدر في مساحة 300×300. التدرجات مأخوذة من عرض PDF للحفاظ على مظهر CMYK، وليست استبدالًا بألوان تقريبية أو نجمة هندسية عامة.

الدماغ يعرض حتى 20,000 جزيء، مع طبقة إضافية موزعة على 10,000 موضع المرجع الأصلي، ويحافظ على هندسة القطعة المجوفة الأصلية، مع إعادة تعيين مجموعات الألوان إلى لوحة Octagram. يجري العرض عبر GPU Instancing وGLSL، مع تفاعل موضعي مع المؤشر، وحركة نابضية، وتفكك وإعادة تجمع. ملفات المصدر وروابطها وبصماتها محفوظة في `assets/source/brain/PROVENANCE.md`. لم تُنسخ أسماء فريق Dala أو ادعاءاته التجارية. التعديلات الخاصة بالشعار والأردن والمظهر الداكن والمحتوى مقصودة، والمطابقة البكسلية الشاملة غير مُدعاة.

الكرة الأرضية تستخدم بيانات **Natural Earth** العامة. موضع العلامة 31.9539° شمالًا و35.9106° شرقًا، دون ادعاء عنوان مكتب. تراخيص Inter وThree.js وإشعار مصدر بيانات الأرض محفوظة مع الأصول، وتظل واجبة عند إعادة توزيعها.

## المجسمات والحركة

- `assets/source/octagram.blend`: مشروع Blender الأصلي القابل للتحرير، بخامات مضمنة.
- `public/assets/models/octagram.glb`: الشعار الحقيقي، مضغوط بـ Meshopt إلى 215,968 بايت.
- `scripts/build_blender_assets.py`: إعادة بناء الشعار من مساراته الدقيقة؛ استُخدم Blender 3.6.23 مع `--gpu-backend opengl` في هذه البيئة.
- `scripts/compress_gltf.mjs`: ضغط دون فقد، مع مقارنة 60 مقطعًا بعد فك الضغط.
- `scripts/build_brain_asset.mjs`: إعادة استخراج بيانات الدماغ من المصادر المضمنة.
- `src/three/choreography.ts`: المسار المتصل والقابل للعكس للمشاهد.
- `src/components/CinematicPost.tsx`: معالجة بصرية تتكيف مع الجودة، وعمق مجال وتوهج خفيف وتحبيب.

المكتبات: React Three Fiber 9 + Drei + Three.js + GSAP. يعمل العرض على WebGL 2. التمرير أصلي، والحركات تلقائية دون أزرار إيقاف في الواجهة، والمحتوى البديل يظهر مع تقليل الحركة أو تعذر WebGL. تُخفّض الجودة وكثافة الجسيمات ودقة العرض حسب أداء الجهاز. لا يعتمد الموقع على WebGPU تجريبي، ولا يحمّل شعار glTF والكرة الأرضية مع بداية الصفحة. الخامات هنا تدرجات صغيرة؛ لا توجد صور فوتوغرافية ضخمة تستدعي خط KTX2.

## الفحص

```sh
npm run check
node checks.mjs
npm run check:models
node scripts/check_brain_asset.mjs
npm run build
npm run test:e2e
```

تستخدم `playwright.config.ts` قناة Google Chrome المثبّتة على الجهاز، إضافة إلى Firefox وWebKit الخاصين بـ Playwright. جهّز المتصفحات قبل تشغيل الاختبارات:

```sh
npx playwright install firefox webkit
```

إذا لم يكن Google Chrome مثبّتًا:

```sh
npx playwright install chrome
```

تثبيت Chromium وحده لا يلبّي إعداد `channel: "chrome"`. يشغّل الاختبار خادم نسخة الإنتاج تلقائيًا على المنفذ 4175، لذلك ابنِ `out/` أولًا. يمكن تشغيل مشروع واحد مثل `npm run test:e2e -- --project=chrome`. اختبار WebGL مخصص لـ Chrome؛ بقية اختبارات الواجهة مهيأة للمتصفحات الثلاثة.

راجع `QA.md` لنتائج الفحص الفعلية وحدوده. وجود الأوامر هنا لا يعني نجاحها في كل بيئة. تُحترم تفضيلات تقليل الحركة، وتبقى الرسومات البديلة والمحتويات متاحة عندما يتعذر WebGL. لم تُقَس مؤشرات Core Web Vitals الميدانية أو حرارة/بطارية هاتف فعلي؛ أهداف التصميم ليست نتائج مقاسة.

## بطاقات الخدمات — 5 نوفمبر 2026

استُبدلت قائمة الخدمات القديمة بثماني بطاقات تضم التفاصيل الـ43 التي قدمها المستخدم. تتوزع البطاقات بشكل متباعد حول مركز القسم وتدور تلقائيًا كالدولاب الدوار، مع بقاء كل بطاقة مستقيمة. النقوش الهندسية مستندة إلى فيديو البطاقات، والألوان من متغيرات هوية المشروع فقط.

اختيار بطاقة يوقف الدوران ويُظهر تفاصيلها داخلها. الأسهم تنقل بين الخدمات، وEscape أو All services يعود إلى الدولاب. يمكن سحب الدولاب، أو إيقافه بزر Pause rotation. يتوقف عند تمرير المؤشر على بطاقة أو التركيز عليها بلوحة المفاتيح، ويحترم زر إيقاف الحركة العام. دون JavaScript أو مع تفضيل تقليل الحركة تظهر البطاقات كتخطيط ثابت بجميع التفاصيل. خيارات الخدمات في نموذج التواصل تتبع المجموعات الثماني الجديدة.

المحتوى في `src/lib/company-content.ts`، والمكوّن في `src/components/ServiceCards.tsx`، والتنسيق في `src/app/services.css`. سجل تدقيق النصوص في `validation/services-content.json`.

شريط التنقل كبسولة عائمة متجاوبة. تبقى مجسمات الشعار مستقيمة، والوضع الداكن هو العرض الوحيد حتى لو كان تفضيل النظام أو التفضيل القديم فاتحًا. كثافة الدماغ تتكيف من 14,000 إلى 20,000 جزيء حسب أداء الجهاز.


تحديث حركة السكرول — 6 نوفمبر 2026: مسارات مستقلة في العمق بدل المسار الجانبي المشترك. يتحرك الدماغ بقوس ثم تلتف جزيئاته إلى دوّامة، وتتجمع وحدات الشعار من أربع جهات مع بقائها مستقيمة، وتدخل الكرة الأرضية من الأسفل ثم تكبر نحو المشاهد. تعود الأشكال الأصلية عند الرجوع بالسكرول. بقيت المجسمات وأصولها وألوانها وكثافة الدماغ كما هي. فحص الحركة والهندسة: `node scripts/check_scene_refinements.mjs`.


تعديل الإيقاع السينمائي: عاد الدماغ للدوران حول محوره مع بقاء شكله كاملًا. تتبع الكاميرا للتمرير مخمّد تدريجيًا دون تعديل موضع الصفحة، وتجميع الشعار يمتد على مسافة تمرير أطول، مع وقفات أوضح وتقريب أهدأ للكرة الأرضية. حركة خامات المجسمات والخلفية تعمل بنسبة 65% من سرعتها السابقة، ويظل التمرير نفسه طبيعيًا.


قسم الفريق يعرض أربع نوافذ ثابتة: الاسم والمنصب والنبذة والمسؤوليات وروابط LinkedIn المتاحة. بطاقتان في الصف على الكمبيوتر وبطاقة واحدة على الهاتف، بألوان الموقع وتفاصيل ظاهرة دائمًا.


بطاقات الفريق بأسلوب ترمنال: شريط نافذة، أوامر عرض زخرفية مثل whoami وcat profile.md، وخط أحادي المسافة بألوان Octagram. جميع البيانات ظاهرة كنصوص HTML، وروابط LinkedIn تظل روابط عادية.


حُذف قسم INDUSTRIES WE SERVE بناءً على الطلب؛ ينتقل ترتيب المحتوى من الخدمات مباشرة إلى المشاريع.


المشاريع تعرض كبطاقات طويلة بتدرجات ألوان الهوية ورسوم خاصة، وثلاثة أعمدة على الكمبيوتر ومعرض قابل للسحب على الهاتف. السهم يفتح تفاصيل المشروع. لا يوجد رابط خارجي لـ Octaclub إلى حين تزويده.
